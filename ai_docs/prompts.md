# 🤖 Copilot Prompt Cheat Sheet

### Client

> Create a new Next.js page that lists all chefs using `useGetChefsWeeklyMenuQuery`.
> Use shadcn Table and TailwindCSS utilities for layout.

### Server

> Create an Express route `POST /meals` that validates input with zod and saves via Prisma.

### Shared Types

> Add a new TypeScript interface for `Review` with id, chefId, rating, and comment fields.

### Tests

> Write a Jest test for `/api/menus` to ensure Prisma returns the correct records.
